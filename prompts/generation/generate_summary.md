# Generate Summary

## Purpose
Create concise, accurate summaries of various content types.

## Context
Use this prompt when you need to distill large amounts of information into key points.

## Prompt Template
```
Create a [LENGTH] summary of the following [CONTENT_TYPE]:

Content:
[INPUT_CONTENT]

Focus on:
- [KEY_AREA_1]
- [KEY_AREA_2]
- [KEY_AREA_3]

Target audience: [AUDIENCE]
Summary format: [FORMAT] (bullet points, paragraph, executive summary, etc.)
```

## Examples
- Meeting notes summarization
- Research paper abstracts
- Project status updates
- Document overviews

## Expected Output Format
- Clear, concise language
- Structured presentation
- Key points highlighted
- Appropriate length for context

## Notes
- Specify desired length (word count, bullet points, etc.)
- Identify target audience
- Include any specific focus areas or exclusions
