# Generate Code

## Purpose
Generate clean, well-documented code based on specifications.

## Context
Use this prompt when you need to create new code from requirements or specifications.

## Prompt Template
```
Generate [LANGUAGE] code that:
- Implements [FUNCTIONALITY]
- Follows [CODING_STANDARDS]
- Includes [DOCUMENTATION_LEVEL] documentation
- Handles [ERROR_CONDITIONS]

Requirements:
[SPECIFIC_REQUIREMENTS]

Context:
[RELEVANT_CONTEXT]
```

## Examples
- API endpoint creation
- Database query functions
- UI components
- Utility functions

## Expected Output Format
- Clean, readable code
- Inline comments
- Function/method documentation
- Error handling where appropriate

## Notes
- Specify language and framework
- Include performance requirements if relevant
- Mention testing requirements if needed
