# Convert Format

## Purpose
Transform content from one format or structure to another while preserving information.

## Context
Use this prompt for data migration, document conversion, or structural transformations.

## Prompt Template
```
Convert the following content from [SOURCE_FORMAT] to [TARGET_FORMAT]:

Source Content:
[INPUT_CONTENT]

Conversion Requirements:
- Source Format: [CURRENT_FORMAT]
- Target Format: [DESIRED_FORMAT]
- Preserve: [ELEMENTS_TO_MAINTAIN]
- Transform: [ELEMENTS_TO_CHANGE]
- Validation: [ACCURACY_REQUIREMENTS]

Specific Instructions:
- [FORMATTING_RULES]
- [STRUCTURE_REQUIREMENTS]
- [CONTENT_MODIFICATIONS]
```

## Examples
- CSV to JSON conversion
- Markdown to HTML
- Database schema transformation
- Document format migration
- API response restructuring

## Expected Output Format
- Converted content in target format
- Validation of data integrity
- Summary of transformations applied
- Error reporting if applicable

## Notes
- Verify data completeness
- Maintain data relationships
- Handle edge cases appropriately
- Provide conversion logs when needed
