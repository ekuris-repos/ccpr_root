# Rephrase Text

## Purpose
Transform text content while maintaining meaning but changing tone, style, or complexity.

## Context
Use this prompt for adapting content for different audiences or communication styles.

## Prompt Template
```
Rephrase the following text according to these parameters:

Original Text:
[INPUT_TEXT]

Transformation Requirements:
- Target Tone: [PROFESSIONAL/CASUAL/FORMAL/FRIENDLY]
- Complexity Level: [SIMPLE/MODERATE/COMPLEX]
- Audience: [TARGET_AUDIENCE]
- Length: [SHORTER/SAME/LONGER]
- Style: [ACADEMIC/BUSINESS/CONVERSATIONAL/TECHNICAL]

Maintain:
- Core meaning and intent
- Key information and facts
- [SPECIFIC_ELEMENTS_TO_PRESERVE]

Adjust:
- [SPECIFIC_CHANGES_NEEDED]
```

## Examples
- Simplifying technical documentation
- Formalizing casual communications
- Adapting content for different age groups
- Converting between writing styles

## Expected Output Format
- Rephrased text meeting all requirements
- Explanation of key changes made
- Verification that meaning is preserved
- Alternative versions if needed

## Notes
- Preserve factual accuracy
- Maintain appropriate context
- Consider cultural sensitivity
- Ensure readability for target audience
