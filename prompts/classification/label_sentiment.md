# Label Sentiment

## Purpose
Analyze and classify the emotional tone and sentiment of text content.

## Context
Use this prompt for understanding customer feedback, social media monitoring, or communication analysis.

## Prompt Template
```
Analyze the sentiment of the following text:

Text:
[INPUT_TEXT]

Provide analysis for:
1. Overall Sentiment: [POSITIVE/NEGATIVE/NEUTRAL]
2. Confidence Score: [0-100%]
3. Emotional Indicators: [SPECIFIC_EMOTIONS]
4. Key Phrases: [SENTIMENT_DRIVING_PHRASES]
5. Intensity Level: [LOW/MODERATE/HIGH]

Context Factors:
- Source: [COMMUNICATION_CHANNEL]
- Audience: [TARGET_AUDIENCE]
- Topic: [SUBJECT_MATTER]
```

## Examples
- Customer feedback analysis
- Social media monitoring
- Employee survey responses
- Product reviews

## Expected Output Format
- Clear sentiment classification
- Confidence metrics
- Supporting evidence
- Actionable insights

## Notes
- Consider cultural and contextual factors
- Account for sarcasm and irony
- Provide reasoning for classification
- Include suggestions for response tone
