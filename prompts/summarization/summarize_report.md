# Summarize Report

## Purpose
Create executive summaries and key takeaways from detailed reports or analyses.

## Context
Use this prompt for condensing lengthy reports into digestible summaries for stakeholders.

## Prompt Template
```
Create a summary of the following report:

Report Content:
[REPORT_CONTENT]

Summary Parameters:
- Target Audience: [EXECUTIVES/TECHNICAL_TEAM/GENERAL_AUDIENCE]
- Length: [WORD_COUNT/PAGE_LIMIT]
- Focus Areas: [KEY_TOPICS_TO_EMPHASIZE]
- Detail Level: [HIGH_LEVEL/DETAILED/TECHNICAL]

Required Sections:
- Executive Summary
- Key Findings
- Recommendations
- Impact Assessment
- Next Steps

Report Context:
- Report Type: [FINANCIAL/TECHNICAL/RESEARCH/AUDIT]
- Time Period: [REPORTING_PERIOD]
- Scope: [COVERAGE_AREA]
```

## Examples
- Financial report summaries
- Technical analysis briefs
- Research study overviews
- Audit report highlights

## Expected Output Format
- Executive summary paragraph
- Bulleted key findings
- Prioritized recommendations
- Clear action items
- Supporting data highlights

## Notes
- Tailor complexity to audience
- Highlight critical issues
- Include quantifiable metrics
- Provide clear recommendations
