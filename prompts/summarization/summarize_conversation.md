# Summarize Conversation

## Purpose
Create structured summaries of meetings, discussions, or chat conversations.

## Context
Use this prompt for meeting minutes, discussion recaps, or conversation analysis.

## Prompt Template
```
Summarize the following conversation:

Conversation:
[CONVERSATION_CONTENT]

Summary Requirements:
- Participants: [LIST_PARTICIPANTS]
- Duration: [TIME_FRAME]
- Format: [MEETING_MINUTES/BRIEF_SUMMARY/ACTION_ITEMS]

Include:
- Key Discussion Points
- Decisions Made
- Action Items with Owners
- Unresolved Issues
- Next Steps

Context:
- Meeting Type: [MEETING_TYPE]
- Project/Topic: [SUBJECT]
- Urgency Level: [PRIORITY]
```

## Examples
- Team meeting minutes
- Client call summaries
- Project status discussions
- Decision-making sessions

## Expected Output Format
- Structured summary with clear sections
- Actionable items with ownership
- Timeline for follow-ups
- Clear decision documentation

## Notes
- Capture key decisions accurately
- Identify action items with deadlines
- Note any conflicts or disagreements
- Include relevant context for future reference
