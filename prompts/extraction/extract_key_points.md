# Extract Key Points

## Purpose
Identify and extract the most important information and insights from content.

## Context
Use this prompt for distilling essential information from lengthy or complex material.

## Prompt Template
```
Extract key points from the following content:

Content:
[INPUT_CONTENT]

Extraction Criteria:
- Priority Level: [CRITICAL/HIGH/MEDIUM/LOW]
- Category Focus: [SPECIFIC_AREAS_OF_INTEREST]
- Audience: [TARGET_AUDIENCE]
- Purpose: [DECISION_MAKING/INFORMATION/ACTION]

Extract:
- Main Arguments/Conclusions
- Supporting Evidence
- Action Items
- Critical Deadlines
- Risk Factors
- Opportunities
- Dependencies

Format Requirements:
- Hierarchical structure (primary/secondary points)
- Source references
- Confidence indicators
- Impact assessment
```

## Examples
- Research paper key findings
- Meeting action items
- Project milestone extraction
- Policy document highlights

## Expected Output Format
- Prioritized key points list
- Supporting evidence for each point
- Relevance scoring
- Context preservation

## Notes
- Maintain logical relationships
- Preserve critical context
- Indicate uncertainty levels
- Prioritize actionable insights
