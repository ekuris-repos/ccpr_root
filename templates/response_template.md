# Response Template

**This is an example response template demonstrating comprehensive response formatting.** Adapt the sections and complexity to match your CCPR implementation tier and organizational needs.

Standard format for AI model responses to ensure consistency and completeness.

## Template Usage by Tier

- **🥉 Tier 1**: Use basic header and main content sections
- **🥈 Tier 2**: Add supporting details and basic validation
- **🥇 Tier 3**: Include comprehensive validation and resources
- **🏆 Tier 4**: Add performance metrics and optimization data

## Response Structure (*Adapt sections to your tier*)

### Header (*Required for all tiers*)
```
## Analysis Summary
[Brief overview of the task/request]

**Status**: [Complete/Partial/Error]
**Confidence**: [High/Medium/Low] *(Tier 2+)*
**Processing Time**: [If applicable] *(Tier 3+)*
```

### Main Content (*Required for all tiers*)
```
### Primary Response
[Main answer or solution]

### Supporting Details *(Tier 2+)*
[Additional context, methodology, or reasoning]

### Recommendations *(Include if helpful for your use cases)*
[Next steps or suggestions if applicable]
```

### Footer (*Tier 2+ - useful for quality assurance*)
```
### Validation *(Scale complexity to your needs)*
- [x] Response addresses the original request
- [x] Information is accurate and current *(basic validation)*
- [x] Appropriate level of detail provided *(Tier 2+)*
- [x] Compliance requirements met *(only if applicable)*

### Resources *(Tier 3+ - helpful for comprehensive responses)*
[Links to related information, documentation, or follow-up resources]
```

## Usage Guidelines (*Adapt to your organizational needs*)

1. **Consistency**: Use template sections appropriate to your tier (*required for all tiers*)
2. **Clarity**: Keep language clear and professional (*essential for all implementations*)
3. **Completeness**: Address aspects of the request appropriate to your context
4. **Compliance**: Include compliance notes only if required for your industry

## Customization (*Scale to your domain needs*)

You may adapt sections based on the specific domain and tier:
- **Technical responses** may include code snippets (*if relevant to your use cases*)
- **Business responses** may include impact analysis (*if useful for your organization*)
- **Compliance responses** must include regulatory references (*only if required*)
