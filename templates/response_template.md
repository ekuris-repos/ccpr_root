# Response Template

Standard format for AI model responses to ensure consistency and completeness.

## Response Structure

### Header
```
## Analysis Summary
[Brief overview of the task/request]

**Status**: [Complete/Partial/Error]
**Confidence**: [High/Medium/Low]
**Processing Time**: [If applicable]
```

### Main Content
```
### Primary Response
[Main answer or solution]

### Supporting Details
[Additional context, methodology, or reasoning]

### Recommendations
[Next steps or suggestions if applicable]
```

### Footer
```
### Validation
- [x] Response addresses the original request
- [x] Information is accurate and current
- [x] Appropriate level of detail provided
- [x] Compliance requirements met (if applicable)

### Resources
[Links to related information, documentation, or follow-up resources]
```

## Usage Guidelines

1. **Consistency**: Always use this template for formal responses
2. **Clarity**: Keep language clear and professional
3. **Completeness**: Address all aspects of the request
4. **Compliance**: Include relevant compliance notes when applicable

## Customization

You may adapt sections based on the specific domain:
- Technical responses may include code snippets
- Business responses may include impact analysis
- Compliance responses must include regulatory references
